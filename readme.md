RGB & LAB Color App

About the App

This is a simple web application made with Python and Streamlit.

The app shows the three primary RGB colors:

- Red
- Green
- Blue

It also allows users to change LAB color values and see the resulting color.

Features

- Shows Red, Green, and Blue colors.
- Allows users to change L, A, and B values.
- Shows the generated color.
- Shows the RGB value of the generated color.
- Shows the HEX color code.

Technologies

- Python
- Streamlit
- GitHub

How to Run

Install the required package:

pip install -r requirements.txt

Run the app:

streamlit run app.py

Deployment

The project can be uploaded to GitHub and deployed using Streamlit Community Cloud.
